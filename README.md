# Paramount International

Static corporate website built with Nuxt 4, Vue 3, TypeScript and Tailwind CSS 4.

## Setup

```bash
npm install
npm run dev
```

Generate the deployable static site with `npm run generate`. Output is written to `.output/public`.

Content is centralized in `app/data/site.ts`; pages are in `app/pages`; shared components are in `app/components`; brand and leadership assets are in `public/assets`.

The contact page is prepared for Netlify Forms. Configure the receiving email in Netlify after deployment.
